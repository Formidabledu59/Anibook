# Anibook

Application web complète (sans framework lourd, pur HTML/CSS/JS) couplée à une API Node.js et une base de données SQLite.

## Fonctionnalités prévues
- **Accueil** : Présentation stylisée du projet.
- **Randomizer** : Piocher un personnage au hasard (avec tags et description).
- **Catalogue** : Liste complète de tous les personnages enregistrés.
- **Quiz** : Mini-jeu de devinettes.
- **Espace Admin** : Interface d'ajout et de gestion des personnages.

## Architecture
- `backend/` : API Node.js avec Express et SQLite.
- `frontend/` : Pages web statiques (HTML, CSS, JS séparés).
