# Anibook
Application web complète (pur HTML5, CSS3, JavaScript vanilla) couplée à un backend Node.js/Express et une base de données SQLite.

## Pages du Projet
- **index.html** : Accueil et indicateur de l'état de l'API.
- **characters.html** : Catalogue complet avec filtres de recherche.
- **random.html** : Randomizer pour piocher un personnage au hasard.
- **quiz.html** : Mini-jeu de quiz interactif.
- **admin.html** : Espace de gestion et d'administration des personnages.

## Stack Technique
- **Frontend** : HTML5, CSS3 (Design personnalisé mode sombre / néon, sans framework lourd).
- **Backend** : Node.js, Express.
- **Base de données** : SQLite.
